# Smart Resource Dispatcher

Утилита для контекстной оптимизации ресурсов, очистки временных файлов, анализа памяти/файла подкачки и применения твиков Windows на **C# (.NET 11.0, `net11.0-windows`)**.

Проект разрабатывается с расчётом как на обычных пользователей (понятные объяснения «простыми словами» и оценка рисков без лишнего жаргона), так и на опытных пользователей/администраторов (технические детали параметров, приоритеты процессов, управление рабочим набором памяти и диагностика).

## Текущие возможности (ядро)

* **Очистка временных файлов (`Core/DiskCleaner.cs`)**:
  * Сканирует пользовательскую временную папку и `C:\Windows\Temp`.
  * Разделяет общий объём временных файлов и объём, доступный к удалению прямо сейчас, с учётом файлов, заблокированных активными процессами.
  * Аккуратно пропускает занятые или недоступные файлы без падения работы утилиты и выводит статистику освобождённого места.
* **Оптимизация памяти и процессов (`Core/MemoryOptimizer.cs`)**:
  * Сбрасывает рабочий набор (`WorkingSet` через `EmptyWorkingSet` из `psapi.dll`) у фоновых процессов с возможностью исключить текущий и целевой процессы.
  * Позволяет изменять класс приоритета (`ProcessPriorityClass`) выбранных процессов.
* **ОЗУ и файл подкачки (`Core/MemoryAndPagefileManager.cs`)**:
  * Определяет объём физической оперативной памяти и текущее/пиковое использование файла подкачки через `System.Management` (`Win32_ComputerSystem`, `Win32_PageFileUsage`).
  * Формирует рекомендации по размеру файла подкачки и поясняет логику расчёта.
* **Твики системы с пояснениями (`Core/TweaksEngine.cs`)**:
  * Проверяет и переключает ключевые параметры реестра Windows (телеметрия/диагностика, фоновая запись экрана и игровые функции, всплывающие уведомления).
  * Содержит описание «простыми словами», пояснение «зачем отключать», уровень риска и техническую справку для продвинутых пользователей.
* **Контекстные профили (`Core/ContextProfileManager.cs`)**:
  * Отслеживает активное окно через Win32 API (`GetForegroundWindow`, `GetWindowThreadProcessId`) и сопоставляет процесс с заданным профилем оптимизации (приоритет процесса и очистка фонового `WorkingSet` при активации).
