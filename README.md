# Smart Resource Dispatcher

Утилита для контекстной оптимизации ресурсов, очистки временных файлов, анализа памяти/файла подкачки и применения твиков Windows на **C# (.NET 11.0, `net11.0-windows`)**.

Проект разрабатывается с расчётом как на обычных пользователей (понятные объяснения «простыми словами» и оценка рисков без лишнего жаргона), так и на опытных пользователей/администраторов (технические детали параметров, приоритеты процессов, управление рабочим набором памяти и диагностика).

## Текущие возможности (ядро)

* **Очистка временных файлов (`Core/DiskCleaner.cs`)**:
  * Сканирует временную папку текущего пользователя и папку `Temp` в каталоге Windows.
  * Показывает предпросмотр доступных файлов старше 24 часов. Занятые файлы, недоступные пути и ссылки пропускаются.
  * Удаляет файлы из предпросмотра только после подтверждения и повторной проверки.
  * В «Очистке Temp» папки Temp выбраны по умолчанию. Миниатюры Проводника (`thumbcache_*.db`) и кэш иконок (`iconcache_*.db`) можно выбрать отдельно. Сканируются только подходящие файлы старше 24 часов непосредственно в `%LocalAppData%\Microsoft\Windows\Explorer`.
  * Предпросмотр показывает объём по выбранным категориям. Проводник не перезапускается: Windows пересоздаст удалённые кэши, а занятые файлы CoreShift пропустит.
  * Опция «Кэш шейдеров DirectX» выключена по умолчанию. Она проверяет только `%LocalAppData%\D3DSCache`, не затрагивая кэши NVIDIA и других драйверов. После удаления первые запуски игр могут подтормаживать из-за повторной компиляции шейдеров.
  * Архив и очередь отчётов об ошибках Windows — две отдельные опции, выключенные по умолчанию. Предпросмотр включает файлы старше 30 дней из `%ProgramData%\Microsoft\Windows\WER\ReportArchive` или `ReportQueue`. Удаление файлов из очереди может лишить Windows возможности отправить ещё не отправленные отчёты.
* **Оптимизация памяти и процессов (`Core/MemoryOptimizer.cs`)**:
  * Сбрасывает рабочий набор (`WorkingSet` через `EmptyWorkingSet` из `psapi.dll`) у выбранного пользовательского процесса.
* **ОЗУ и файл подкачки (`Core/MemoryAndPagefileManager.cs`)**:
  * Читает сведения об ОЗУ, выделенной памяти и файлах подкачки через Win32 API и WMI.
  * Формирует рекомендации по размеру файла подкачки и поясняет логику расчёта.
* **Твики системы с пояснениями (`Core/TweaksEngine.cs`)**:
  * Показывает состояние политик диагностики, игрового захвата и центра уведомлений. Позволяет применить поддерживаемый твик и восстановить исходное значение.
* **Контекстные профили (`Core/ContextProfileManager.cs`)**:
  * Отслеживает активное окно и меняет приоритет выбранного приложения в фокусе, восстанавливая исходный приоритет, когда фокус меняется или профиль останавливается.

## Стек и окружение

* **Язык и платформа**: C#, `.NET` (`net11.0-windows`)
* **Пакеты NuGet**: `System.Management` и его зависимость `System.CodeDom`
* **Редакторы / среда**: VS Code / Zed, PowerShell, Git

## Графический интерфейс CoreShift

Запуск на Windows: `dotnet run --project Desktop/CoreShift.Desktop.csproj`.

Вкладка **«О компьютере»** показывает имя ПК, версию и архитектуру Windows, процессоры, объём ОЗУ, видеоадаптеры и накопители. Сведения загружаются при первом открытии вкладки. Если Windows не вернула отдельную характеристику, она отмечается как недоступная.

## Запуск и сборка

Установите [.NET 11 SDK](https://dotnet.microsoft.com/download/dotnet/11.0) версии из [`global.json`](global.json). Выполните из корня репозитория на Windows:

```powershell
dotnet restore Desktop/CoreShift.Desktop.csproj --locked-mode
dotnet build Desktop/CoreShift.Desktop.csproj --no-restore
dotnet run --project Desktop/CoreShift.Desktop.csproj --no-build
```

Предпросмотр очистки без удаления из консоли: `dotnet run -- clean --dry-run`.
